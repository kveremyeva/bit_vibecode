# Инструкция для проверяющего

## Как открыть приложение

1. Перейдите по ссылке работающего приложения (адрес вида
   `https://app-<id>.vibecode.bitrix24.tech`, выдаётся после публикации).
2. Авторизуйтесь в портале Битрикс24 (если ещё не вошли) — шлюз платформы
   пропустит вас как авторизованного пользователя, и приложение увидит
   данные именно того портала и с правами того пользователя, под которым
   вы вошли.
3. По умолчанию выбран период **«Этот месяц»**. На дашборде четыре блока:
   * **фильтр периодов** — «Сегодня», «Вчера», «Эта неделя», «Этот месяц»,
     «Произвольный период» (даты «от»/«до»);
   * **KPI** — сумма открытых сделок, количество выигранных, средний чек;
   * **воронка по стадиям** — количество и сумма сделок по стадиям;
   * **последние сделки** — таблица до 20 сделок (название, сумма, стадия,
     ответственный).
4. Переключите период — все блоки пересчитаются автоматически. Сверху видно
   время обновления снимка данных и предупреждение, если портал долго
   отвечает (это норма для нагруженного портала).
